# 🧮 Simple Calculator

A fully functional, web-based calculator designed to perform standard arithmetic operations. This project showcases the practical application of vanilla JavaScript for mathematical logic and DOM manipulation, paired with a clean and interactive user interface.

## ✨ Features
* **Core Arithmetic:** Supports basic mathematical operations including addition, subtraction, multiplication, and division.
* **Interactive UI:** Features a responsive layout with interactive buttons for a seamless user experience.
* **Real-time Calculation:** Instantly processes user input and displays accurate results.
* **Clean Codebase:** Built entirely with core web technologies, demonstrating clear separation of structure, style, and logic.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3
* **Logic:** Vanilla JavaScript (ES6+)
* **Deployment:** Hosted live via GitHub Pages
